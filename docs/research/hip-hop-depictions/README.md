# Depiction of Black Female Artists — Gallery / Link Compilation

Per `docs/research/Hip Hop.md` Q9: how Black female artists (not female AI artists) are commonly depicted by the companies in this research, and for whose gaze.

This directory holds:
- `links.md` — a running list of URLs (gallery pages, videos, compilations, press, artist pages) with a one-line note on what each shows and which company/artist it belongs to.
- `analysis.md` — the author-facing synthesis: the recurring depiction patterns, the visual/rhetorical tropes, and the "for whose gaze" argument. (Written in Task 6.)

`links.md` is populated incrementally as sources are found.
