# AI Hip-Hop Lyrics Corpus

Local aggregation of the full lyrics of the most popular AI hip-hop songs, per `docs/research/Hip Hop.md` Q10.

One file per song: `<NN>-<artist-slug>-<song-slug>.md`.

Each file has a header block:
- artist (AI avatar or human AI-user, as established in Task 1)
- title
- platform(s) where it is most streamed (Spotify / YouTube Music)
- stream count (best available, with source)
- source URL for the lyrics
- fetched date

The body is the full lyrics, verbatim. If full lyrics are unavailable, save what is available and note the gap in the header.
